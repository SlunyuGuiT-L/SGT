# SGT 自动喊话

Omni Toolbox 的在线模块：**进本 / 进战 / 脱战 / 血量过低**时，自动在指定频道发送一条可定制的消息。

默认全部关闭 —— 装上、启用模块本身都不会发任何话，需要自己开触发器。

## 安装

卫月 → 插件设置 → **在线模块** → 填仓库地址：

```text
https://github.com/SlunyuGuiT-L/SGT
```

刷新后安装 `SGT 自动喊话`，首次安装默认关闭，去「树树妙妙屋 → 在线」里启用。

## 使用

| 操作 | 说明 |
|---|---|
| `/omni SGTAutoShout test` | 按当前设置立刻发一条（不受触发器和冷却限制，用来验证频道和文案） |
| 设置面板 | 「树树妙妙屋」里找到本模块，四个触发器可各自开关 |

### 触发器

| 触发器 | 触发时机 |
|---|---|
| 进入副本时 | 检测到进入副本的瞬间（副本内启用模块不会立刻触发） |
| 进入战斗时 | 进战的那一瞬间 |
| 脱离战斗时 | 脱战的那一瞬间 |
| 血量过低 | 血量从阈值之上掉到阈值之下时 |

### 频道

小队 `/p`（默认）、团队 `/a`、默语 `/s`、呼喊 `/y`。

> 呼喊频道在副本内通常不可用，选了之后游戏会自己提示失败 —— 这不是模块的问题。

### 文案占位符

| 占位符 | 替换成 |
|---|---|
| `{zone}` | 当前区域名 |
| `{hp}` | 当前血量百分比 |
| `{name}` | 角色名 |
| `{job}` | 当前职业名 |

例：`我的血量 {hp}%，注意治疗。`

### 发送控制

- **最小发送间隔**：默认 5 秒，防止连续触发时刷屏；
- **同一副本内每个触发器只发一次**：默认开启。关掉之后，同一个副本里每次进战/脱战都会各发一次（仍受间隔限制）；
- 文案里的换行会被替换成空格并裁到 200 字以内，避免一条消息发成多条命令。

## 已知限制

- 「进入副本」用副本标记判断，个别特殊场景（如无人岛）不计入；
- 只有在本模块启用期间发生的状态变化才会触发，启用前的状态作为基线；
- 每个触发器只有一条文案，不支持按副本/职业切换。

## 开发

```bat
publish.cmd -Check -Update
```

校验清单字段 → 用本机已安装宿主 + 卫月开发 DLL 编译 → 契约预检 → 重算 SHA256 写回 `TreeHouseModules.json`。
改了任何字节都要重跑，否则宿主的摘要校验会拒绝加载。

需要 Omni **1.1.8.2** 及以上（新版在线模块接口，API 1）。
